## Reddit / r/chrome

### Title

I built a visual Alt-Tab for people with too many Chrome tabs

### Body

I regularly end up with so many tabs that the tab strip becomes a row of tiny favicons, so I built TabScroll.

Press `Ctrl+Shift+K` and it opens a full-screen visual switcher for the current window. You can move with the mouse wheel or arrow keys, then press Enter to switch.

It shows titles, URLs, favicons, and previews where Chrome allows them. Everything stays local—there is no account, analytics, advertising, or telemetry.

One transparent caveat: Chrome shows its native debugging banner while TabScroll captures background-tab previews. The extension uses that access only during the capture and detaches afterward.

## Show HN

### Title

Show HN: TabScroll – visual Alt-Tab for crowded Chrome windows

### Body

TabScroll is a small Manifest V3 extension I built to make crowded Chrome sessions easier to navigate.

It opens a full-screen carousel of the current window's tabs with `Ctrl+Shift+K`. Scroll or use the arrow keys, then press Enter to activate the selected tab. It uses titles, URLs, favicons, and temporary local previews to make tabs recognizable.

There is no backend, login, analytics, or telemetry. The source and permission explanations are public: https://github.com/Cpudados/tabsroller

Demo and install: https://cpudados.github.io/tabsroller/
