What does the optional tab-details permission do? +

It lets TabScroll read the titles, addresses, and favicons of tabs that are currently open so each card is recognizable. Chrome may call this browsing-history access because open-tab addresses are visible. TabScroll does not read stored history, and you can decline and use the limited view.
